# pr-triage-sandbox

This repository is the sandbox for a hands-on lab where students practice triaging pull requests the way a maintainer would: reading the diff, checking CI status, leaving reviews, and deciding what happens next — all against deliberately simple, throwaway changes.

Everything here is disposable. This is a practice sandbox, not a real project, so open, comment on, and close pull requests freely — nothing in this repository should ever be merged.
